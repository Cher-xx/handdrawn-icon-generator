# Reference Icon Manifest

All files are 100×100 RGBA PNG images.

## Approved Style Exemplars

- `style_outline_pressure.png`: primary outline reference; asymmetrical wax-crayon contour with visible pressure-based width changes, local retracing, and non-repeating dry gaps
- `style_airbrush_shadow.png`: optional depth reference; preserves the crayon outline while adding a deep-brown airbrush shadow at the viewer-right interior edge with a soft inward fade

Always use `style_outline_pressure.png`. Use `style_airbrush_shadow.png` only when the user requests a more dimensional result or explicitly asks for shading.

## Food and Drink

- `bubble_tea.png`, `pink_drink.png`: cups, straws, loose dark outlines
- `coffee.png`: muted palette, rounded form, soft shadow
- `donut.png`, `pudding.png`: compact desserts, warm brown shading
- `cake.png`, `strawberry_cake.png`: simple cakes, minimal decoration
- `ice_cream_cone.png`: narrow object, outlined detail

## Objects and Symbols

- `book.png`, `camera.png`, `gift.png`: simplified everyday objects
- `phone.png`, `note.png`: minimal symbolic marks
- `crown.png`, `star.png`, `heart.png`, `flower.png`: bold flat silhouettes
- `salary.png`: compact symbolic object with small line accents
- `countdown1.png`, `countdown2.png`, `countdown3.png`: hand-drawn numerals and underline

## Animals and Nature

- `cat.png`: sparse facial suggestion using separated marks
- `sparrow.png`: rounded animal character with warm outline
- `butterfly.png`: symmetric subject with vivid purple/pink fill
- `wave.png`: repeated blue strokes and translucent fill

## Activities and Mini-scenes

- `ride_a_bike.png`: delicate outlined object
- `outdoor.png`: stick figure and directional symbol
- `party.png`: tiny celebratory glasses with sparse accents
- `beach.png`, `seaside.png`: extremely simplified landscapes

## Selection Shortcuts

- Bold symbol: use `star`, `heart`, `flower`, plus one outlined object.
- Food/drink: use the closest food reference, `coffee`, and `strawberry_cake` or `pudding`.
- Animal: use `sparrow`, `cat`, and `butterfly`.
- Object: use `camera`, `book`, `gift`, and `ride_a_bike`.
- Scene/activity: use `beach`, `seaside`, `outdoor`, and `party`.
